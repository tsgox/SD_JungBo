변수와 자료형

변수: 값을 저장하는 기억 공간. 변수명: 기억 공간을 식별하는 이름.

  • 가능: 대소문자, 한글, 언더바(_), 숫자
  • 불가: 첫 글자 숫자, 파이썬 예약어
  • 대소문자 구별
True는 예약어지만 true는 대소문자가 달라 변수명으로 쓸 수 있다. and, or, elif, return, break, continue 등은 사용 불가.

리스트

여러 데이터를 하나의 이름으로 관리. 요소의 자료형이 서로 달라도 된다.

요소(원소): 각각의 값인덱스: 위치, 0부터슬라이싱: 일부 추출
append맨 뒤에 추가

remove는 같은 값이 여러 개면 첫 번째 요소만 삭제.

다차원 데이터 구조

데이터를 행과 열 또는 여러 차원으로 구성하여 저장. 차원: 데이터 구조를 구성하는 요소의 수.

차원구성사례
1차원한 방향한 과목의 학생별 점수
2차원행, 열학생별 여러 과목 점수
3차원행, 열, 높이여러 반의 학생별 여러 과목
  • 흑백 이미지 = 2차원, 밝기 0~255 (0 어둡고 255 밝음)
  • 컬러 이미지 = 3차원, R·G·B 색상 정보

딕셔너리

키(key)와 값(value)이 쌍으로 이루어진 데이터 집합.

  • 키: 데이터를 식별하기 위한 기준
  • 값: 키에 대응하는 데이터

조건문

단순 if참일 때만 실행, 거짓이면 실행 안 함
if~else참·거짓 각각 다른 명령
중첩조건문 안에 조건문
다중 if~elif~else여러 조건 순차 검사
elif에는 조건식이 반드시 있다. else 없이 elif만 여러 개 써도 된다.

반복문과 제어

  • for: 주로 정해진 범위 반복. 중첩 for는 내부 for가 끝나면 외부 for의 다음 반복
  • while: 조건식이 참인 동안 반복, 거짓이면 탈출. 조건 변수는 미리 초기화하는 경우가 많다
  • 조건식이 항상 참 → 무한 반복
break반복문 자체를 종료
continue현재 반복의 나머지를 건너뛰고 계속

기계학습의 다양한 모델

회귀지도학습 · 연속적인 수치 예측

선형 회귀

입력값과 결과값의 관계를 선형 형태의 함수로 나타내 수치 예측.

  • 단순 선형 회귀: 특징 1개
  • 다중 선형 회귀: 특징 2개 이상
분류지도학습 · 미리 정의된 범주(클래스) 판별

결정트리

트리 구조 기반. 루트부터 분기마다 특징의 분류 기준을 만들어 단계적으로 분류.

트리가 너무 깊으면 예측 성능이 떨어질 수 있음. 회귀에도 적용 가능.

k-최근접 이웃(kNN)

  1. 기존 데이터와 예측 데이터의 거리 계산
  2. 가까운 순서로 k개 이웃 선택
  3. 다수가 속한 클래스로 분류(다수결)
  • 유클리디안 거리: 두 점의 직선거리
  • 맨하튼 거리: 좌표축 방향 거리의 합
  • k 값에 따라 결과가 달라질 수 있음
  • 모델 생성 전 데이터 정규화 필요

로지스틱 회귀

로지스틱 회귀 함수로 특정 클래스에 속할 확률(0~1) 예측, 주로 0.5를 기준으로 분류.

인공 신경망

뇌 신경계의 정보 처리 방식 모방, 수많은 노드가 신호를 주고받음.

연결이 깊어질수록 더 복잡한 문제 해결 가능, 깊어진 형태가 심층 신경망.

군집화비지도학습 · 비슷한 데이터끼리 그룹화

K-평균 군집화

중심점과 데이터 사이의 거리로 K개 군집 구성.

  1. 군집 개수 K 결정
  2. 각 군집의 중심점 설정
  3. 가장 가까운 중심점에 데이터 할당
  4. 군집 데이터의 평균 위치로 중심점 변경
  5. 중심점이 변하지 않을 때까지 반복

기계학습 구현 과정

  1. 문제 정의: 기계학습으로 해결 가능한지 판단
  2. 데이터 수집·전처리: 통계 정보·핵심 속성 확인, 결측치·이상치 처리
  3. 모델 선정·학습: 훈련 데이터로 학습
  4. 모델 평가: 테스트 데이터로 성능 평가·개선
  • 결측치: 값이 누락된 부분 / 이상치: 일반 범위에서 크게 벗어난 값
  • 과정은 생략·반복될 수 있고, 평가 결과에 따라 모델·속성·설정값을 바꿔 개선

저작권과 CCL

저작권: 창작자가 저작물에 가지는 권리, 목적은 창작 활동 장려.

CCL: 저작자가 일정한 조건에서 자유로운 이용을 허락하는 라이선스.

  1. 이용할 저작물 결정
  2. 보호받는 대상인지 확인
  3. 이용 방식이 저작권법상 허용되는지 확인
  4. 저작권자에게 이용 허락
  5. 허락 범위에서 이용, 저작자·출처 표시

범위: 첨부 노트 기준. 코드 예제, 실습, Orange3, CSV·파일 입출력, 원본에 본문이 없는 컴퓨팅 시스템·데이터 단원과 문제 분석·추상화·알고리즘 단원은 제외하였다. 비교 연산자 행은 원본 표가 깨져 있어 파이썬 표준 비교 연산자로 채웠다.
